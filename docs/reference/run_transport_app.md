# Launch the Victorian Public Transport Explorer

Launches the interactive Shiny application included in the
`victransport` package.

## Usage

``` r
run_transport_app()
```

## Value

Invisibly returns the Shiny application result.

## Details

The application allows users to explore average daily public transport
patronage in Victoria by filtering transport modes, day types, reporting
years and months. Interactive charts and key findings update
automatically when the selected filters change.

## Examples

``` r
if (FALSE) { # \dontrun{
run_transport_app()
} # }
```
